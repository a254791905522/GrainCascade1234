Tap once.Let the cascade decide.

GrainCascade is a chalk-sketched puzzle of circles and connections. Tap a circle to add one unit of charge. Each node has a capacity—push past it and the circle overflows, resets, and permanently sends one unit to every neighbor, which can chain across the whole diagram. Land the exact required charge on every target using as few taps as you can, and never overflow a protected circle.

One tap, one grain

Each tap on a chalk circle adds exactly one charge unit. There is no drag-to-fill meter—the puzzle is planning which node to tap next so cascades land where you need them.

Overflow travels

When charge exceeds capacity, the circle bursts: it drops to zero and sends one permanent unit to each linked neighbor. Those neighbors can overflow in turn—one tap can ripple through the whole sketch.

Three states on the board.

Read the diagram before you tap. Protected circles are hard limits—if one overflows, the puzzle fails. Ordinary targets must end on the exact number shown, not one grain over or under.

  • State A

    Below capacity

    The circle still accepts charge. Safe taps add a unit without triggering a burst.

  • State B

    At capacity

    The next tap will overflow. Use that moment deliberately when you want to push charge into neighbors.

  • State C

    Overflowing

    The node resets to zero and distributes one unit along every connection—often starting a chain reaction across the network.
